# 数据分析组合包

这个包负责把 Python 代码运行器、数据分析工具和操作说明组合起来。

## 它做什么

- 关掉 DeepSeek Harness 自带的 TypeScript 代码运行器。
- 挂载 Python 代码运行器。
- 挂载数据分析工具。
- 挂载数据分析操作说明。
- 挂载网页端的图表和报告展示模块。
- 挂载用户确认按钮。

## 模型体验

这个包本身不直接给模型增加内容。模型看到的内容由它挂载的那些部分提供。

## 已知限制

- 它只负责组合，不负责网页展示和用户身份配置。
- 它一次只使用一个代码运行器，不能同时使用 Python 和 TypeScript 两种运行器。
